
# 👁 vnxORACLE System: Technical Passport & Roadmap

**vnxORACLE** — это высокоуровневая нейро-надстройка над экосистемой vnxMATRIX. Система спроектирована как гибридный ИИ-узел с элементами самозащиты, отказоустойчивости и глубокой интеграцией в «Матрицу».

## 🛠 1. Серверная Среда (Environment)

| Параметр | Значение |
| --- | --- |
| **Хостинг** | TimeWeb Cloud (Ubuntu 22.04 LTS) |
| **Корневая директория** | `/opt/vnxORACLE_system/` |
| **Python Version** | 3.10.x |
| **База данных** | SQLite 3 (`oracle.db`) |
| **DB Mode** | **WAL (Write-Ahead Logging)** + `PRAGMA synchronous = NORMAL` |
| **Системная служба** | `vnx-oracle.service` |

### 📟 Команды управления (Aliases)

* `oracle-restart`: Перезагрузка службы бота через `systemctl`.
* `oracle-log`: Просмотр логов в реальном времени (`journalctl -u vnx-oracle -f`).
* `oracle-status`: Проверка состояния процесса.

## 🧬 3. Текущие Технологические Решения

### 🛡 Обход блокировок (Cloudflare Bypass)

Система использует библиотеку `curl_cffi` с имперсонацией **Chrome 124**. Это позволяет обходить TLS-блокировки ElevenLabs и других API, имитируя поведение реального пользователя.

### ⚡️ Отказоустойчивость (Hybrid TTS)

Реализована логика **Triple-Value Return**:

1. Метод `text_to_speech` возвращает кортеж: `(audio_data, engine_name, is_fallback)`.
2. Если ElevenLabs (Primary) выдает 403 или 429, система переключается на OpenAI TTS.
3. В интерфейсе пользователя появляется метка `⚠️ Используется резервный ИИ`, сохраняя прозрачность работы.

### 💾 Оптимизация БД («Архитектор памяти»)

* **WAL Mode**: Чтение не блокирует запись.
* **Context Control**: Реализован вложенный SQL-запрос для `get_history`, который извлекает последние  сообщений, но возвращает их в правильной хронологии.
* **Row Factory**: Доступ к данным по именам столбцов (`row['content']`), что исключает ошибки при изменении структуры таблиц.

## ⚠️ 4. Техно-Кодекс (Правила Безопасности)

1. **Связка Кнопка-Код**: Константы `BTN_` в `config.py` — это ключи. Любое изменение текста кнопки требует немедленного обновления логики в `handlers.py`.
2. **Режим Состояний (FSM)**: Логика ожидания (например, текста для озвучки) реализована через `context.user_data['mode']`. При завершении задачи режим обязан сбрасываться в `None`.
3. **Принцип Audio Input**: Все транскрипции помечаются тегом `[Audio Input]`. Системный промпт проинструктирован игнорировать этот тег и отвечать по существу.
4. **Graceful Shutdown**: При остановке системы база должна корректно закрывать соединения (`PRAGMA optimize` перед выходом).

## 🚩 5. Ошибки Прошлого (Lessons Learned)

* **Ошибка 403**: Использование стандартного `aiohttp` для ElevenLabs ведет к вечному бану IP. **Решение:** Только `curl_cffi`.
* **Зависание кнопок**: Забытый `query.answer()` в инлайн-меню блокирует интерфейс. **Правило:** Любой callback должен быть отвечен.
* **Потеря контекста**: При отправке слишком длинной истории API выдает ошибку. **Решение:** Динамический лимит глубины истории на основе тарифа (START=10, PRO=30, NEO=60).
