## 🎨 Дизайн-философия

### Принципы (как у Apple):
1. **Минимализм** — ничего лишнего
2. **Простота** — интуитивная навигация
3. **Жидкое стекло** — glass-morphism из iOS 26
4. **Плавные анимации** — Framer Motion
5. **Респект к контенту** — текст на первом месте

### Палитра:
- **Dark surfaces:** #05070C → #1E2636 (stepped tonal ladder)
- **Accent:** #38BDF8 (cyan, tech-направленность)
- **Supporting:** приглушённые тона, никаких ярких градиентов

### Типографика:
- Fluid scaling: `clamp()` для всех размеров
- Custom properties: `var(--font-heading)`, `var(--font-body)`
- Tight tracking на заголовках, generous line-height на body

### Layout:
- **Grid-first:** CSS Grid для структуры
- **Flexbox:** только внутри компонентов
- **Радиусы:** 999px pills на кнопках, токенизированные значения

### Roles Section (КАНОН):

**Кого вы берете в команду?**

Мы не продаем чат-ботов. Мы сдаем в аренду готовых специалистов, которые уже обучены решать задачи вашей ниши.

1. **Специалист Техподдержки (L1/L2)**
   Мгновенно закрывает 80% тикетов. Знает всю документацию. Не устает.

2. **Менеджер по Продажам**
   Квалифицирует лидов, консультирует по каталогу, доводит до оплаты.

3. **Внутренний Ассистент (HR/Офис)**
   Помогает вашим живым сотрудникам находить регламенты и онбордить новичков.

### How It Works Section (КАНОН):

**Сотрудник как Услуга (EaaS)**

**01. Собеседование**
Вы рассказываете, какие задачи должен закрывать цифровой сотрудник и к каким базам данных иметь доступ.

**02. Стажировка**
Мы разворачиваем ядро на базе vnxORACLE, обучаем нейросеть вашей специфике и интегрируем в ваши процессы.

**03. Выход на работу**
Сотрудник начинает работу за фиксированную абонентскую плату. Никаких больничных, налогов и отпусков.

### Trust Section (КАНОН):

**Разум, которому можно доверить бизнес.**

1. **Изолированная память**
   Данные вашей компании остаются только внутри вашего контура.

2. **Управляемая логика**
   Сотрудник не галлюцинирует и строго следует заданному Tone of Voice.

3. **Непрерывная эволюция**
   Вы получаете апдейты AI-ядра автоматически, без скрытых платежей за разработку.

## 📐 Процесс изменений

### Workflow:

1. **Предложение изменения** → документируется в issue/docs
2. **Обсуждение** → согласование с владельцем проекта
3. **Прототип** → создание в отдельной ветке
4. **Review** → утверждение или возврат на доработку
5. **Merge** → в main только после утверждения
6. **Документация** → обновление канонических текстов

### Откат изменений:

Все канонические тексты хранятся в этом файле (`BRAND_IDENTITY.md`).

При необходимости отката:
```bash
git revert <commit-hash>
# или
git checkout <previous-version> -- landing/src/App.jsx
```
