
📋 Roadmap: vnxORACLE AI System (The Mind)
Статус: ONLINE (Production)

Версия: 2.1.5 (Stable Hybrid Edition)

Девиз: "Избыточность — это надежность. Синтез — это свобода."

✅ 1. COMPLETED: Фундаментальный Слой
Архитектура, доказавшая свою устойчивость в условиях блокировок.

[x] Core 2.0: Асинхронное ядро (PTB 20.7) с разделением на Singleton-сервисы.

[x] Database 2.1: SQLite в режиме WAL с поддержкой сессий и хронологического извлечения контекста.

[x] Hybrid Audio: Система Double-Fallback (ElevenLabs ↔ OpenAI) с использованием curl_cffi для обхода Cloudflare 403.

[x] Logic Gate: Полная интеграция с Google Sheets для управления тарифными сетками (START, PRO, NEO).

[x] UI/UX: Динамические инлайн-меню, "умные" кнопки истории и подвал сообщения (Blockquote) с метаданными.

🚀 2. PRIORITY: Активная Фаза (High Priority)
Технологии, которые внедряются прямо сейчас для расширения когнитивных способностей.

👁 Vision & Perception (Зрение)
[ ] GPT-4o Vision Integration: Реализация метода analyze_image в ai_engine.py. Поддержка форматов JPG/PNG.

[ ] Multimodal Context: Возможность ИИ «видеть» изображение в контексте текущего диалога (например: "Исправь ошибку на этом скриншоте").

[ ] OCR & Document Analysis: Распознавание печатного текста и таблиц с фотографий для мгновенного анализа.

[ ] Handler Evolution: Доработка handle_photo и handle_document для автоматической пересылки медиа в Vision-движок.

🛡 Stability & Security (Надежность)
[ ] Admin Nerve System: Автоматическая отправка уведомлений Архитектору при возникновении критических ошибок (API 429/500) или сбоев в базе.

[ ] The Vault (Auto-Backup): Ежедневный дамп oracle.db и отправка архива в защищенный канал-хранилище.

[ ] Graceful Recovery: Механизм автоматической очистки временных файлов голоса (.ogg, .mp3), если бот был перезагружен во время обработки.

🟢 3. ROADMAP: Будущая Эволюция (Low Priority)
Масштабирование экосистемы vnxMATRIX.

[ ] TWA (Telegram Web App): Визуальный интерфейс для управления сессиями, выбора голосов и мониторинга токенов.

[ ] Suno AI / Udio: Генерация полноценных музыкальных треков по текстовому описанию.

[ ] Video Generation: Интеграция API (Luma/Kling) для создания коротких видео-фрагментов.

[ ] RAG System: Подключение персональной базы знаний (пользователь загружает PDF-библиотеку, и бот отвечает на основе её данных).

[ ] Crypto-Native Billing: Автоматическая оплата подписок через CryptoBot API (USDT/TON).

🦾 Техно-Кодекс проекта
Принцип Изоляции: Сбой в модуле audio_studio не должен мешать работе ai_engine.

Защита Потока: Любой await должен иметь timeout. Оракул не ждет медленные серверы дольше 45 секунд.

Scannability First: Ответы бота должны быть читаемы за 3 секунды. Жирный шрифт, списки, блоки кода.

Privacy First: Все присланные пользователем медиа-файлы для анализа должны удаляться с сервера сразу после обработки.
