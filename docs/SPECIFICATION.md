# 👁 vnxORACLE: Technical Specification v2.1.0

**Project Name:** vnxORACLE (The Mind of vnxMATRIX)

**Status:** Stable / Production Ready

**Date:** 2026-01-27

**Environment:** Linux (Ubuntu 22.04 LTS)

---

## 1. ЦЕЛЬ И ФИЛОСОФИЯ СИСТЕМЫ

**vnxORACLE** — это высокотехнологичный интерфейс взаимодействия с нейронными сетями, выполняющий роль центрального узла экосистемы **vnxMATRIX**.

* **Философия:** Предоставление свободы доступа к информации через «красную таблетку» ИИ.
* **Стиль:** Киберпанк, минимализм, высокая точность.
* **Задача:** Агрегация LLM, синтез речи, генерация медиаконтента и управление пользовательскими правами.

---

## 2. АРХИТЕКТУРА И СТЕК ТЕХНОЛОГИЙ

### 2.1. Технологический стек

* **Core:** Python 3.10+ (Asyncio).
* **Interface:** `python-telegram-bot` (v20.7+).
* **Network:** `curl_cffi` (Имперсонация Chrome 124 для обхода Cloudflare) и `aiohttp`.
* **Database:** `SQLite 3` с оптимизацией **Write-Ahead Logging (WAL)**.
* **Admin/Billing:** `Google Sheets API` (gspread) — реестр прав доступа.

### 2.2. Структура системы (Modular Design)

```plaintext
vnxORACLE/
├── main.py             # Входной шлюз и инициализация циклов
├── loader.py           # Синглтоны сервисов (Memory, AI, Studio, Sheets)
├── config.py           # Константы, промпты и ключи безопасности
├── handlers.py         # Логика обработки сигналов и состояний (FSM)
├── keyboards.py        # Интерфейс (Reply/Inline конструкции)
├── oracle.db           # Локальное хранилище данных
└── services/
    ├── database.py     # Низкоуровневая работа с памятью
    ├── ai_engine.py    # Текстовый разум (OpenRouter/Whisper)
    ├── audio_studio.py # Синтез звука (Hybrid TTS: ElevenLabs + OpenAI)
    └── sheets_mgr.py   # Синхронизация с Матрицей Доступов

```

## 3. МОДЕЛЬ ДАННЫХ (DATABASE SCHEMA)

Система использует реляционную структуру для хранения «цифровых следов» пользователей.

### 3.1. Таблицы

1. **`users`**: Баланс токенов и идентификация (`user_id`, `total_tokens`).
2. **`sessions`**: Коллекции диалогов (`id`, `user_id`, `title`, `is_active`).
3. **`messages`**: Содержимое памяти (`session_id`, `role`, `content`, `model`, `timestamp`).

## 4. ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

### 4.1. Гибридная Озвучка (Evolutionary TTS)

**Уникальная фича:** Система защищена от блокировок провайдеров (ElevenLabs).

* **Primary:** ElevenLabs через `curl_cffi` (Chrome 124 TLS Fingerprint).
* **Fallback:** При обнаружении 403 ошибки или капчи Cloudflare, система мгновенно переключается на OpenAI `tts-1`.
* **Output:** Пользователь получает аудио в формате `.mp3` (Audio File) с метаданными.

### 4.2. Текстовый Интеллект (LLM Hub)

Поддержка мультимодельности через OpenRouter:

* **START:** GPT-4o Mini (быстрые ответы).
* **PRO:** GPT-4o (флагманская логика).
* **NEO:** Claude 3.5 Sonnet (продвинутый кодинг и анализ).
* **FREE:** Доступ к моделям Chimera, Liquid и Mistral.

### 4.3. Распознавание Речи (Whisper STT)

Обработка голосовых сообщений любой длины. Автоматическая транскрибация и передача текста в активную модель с пометкой `[Audio Input]`.

---

## 5. БИЗНЕС-ЛОГИКА И ТАРИФЫ

### 5.1. Матрица Доступов (Google Sheets)

Проверка прав осуществляется перед каждым запросом.

* **Тарифы:** START (10 сообщений контекста), PRO (30 сообщений), NEO (60 сообщений).
* **Paywall:** При отсутствии активной записи в Google Sheets, система блокирует доступ и выводит меню оплаты.

### 5.2. Управление сессиями

Пользователь может вести неограниченное количество диалогов. Переключение между чатами происходит через Inline-меню «История», что позволяет изолировать контексты разных задач.

---

## 6. БЕЗОПАСНОСТЬ И ОТКАЗОУСТОЙЧИВОСТЬ

* **Environment:** Все ключи изолированы в `.env`.
* **Error Handling:** Каждый API-запрос обернут в асинхронный `try-except`.
* **Graceful Restart:** Поддержка службы `systemd` для автоматического восстановления после сбоев.
